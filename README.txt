ШКОЛЬНЫЕ ЗВОНКИ
Версия 1.1
================================================================

Лёгкая программа автоматических школьных звонков для Windows 10
и Windows 11. Установка не требуется: программа запускается одним
файлом SchoolBells.exe. Расписание, настройки, музыка и записи
хранятся в папке SchoolBellsData рядом с программой.

Автор: Иван Семёнов
GitHub: https://github.com/IvanSemenovVetarion
Лицензия: MIT (см. файл LICENSE)

Возможности:
  - расписание звонков на каждый день недели;
  - отдельный шаблон «Короткий день» и отметка коротких дней;
  - ввод времени в формате 08:00, 0800 или 800;
  - копирование расписания одного дня сразу в несколько дней;
  - своя MP3-мелодия для начала и конца урока;
  - несколько цветовых тем и автоматическая смена по сезону;
  - зимняя тема с анимированными снежинками;
  - музыка на всю школу: по расписанию и вручную;
  - голосовые объявления с микрофона;
  - работа в области уведомлений (трее), автозапуск;
  - журнал звонков и журнал ошибок;
  - низкие требования — подходит для старого ноутбука.


----------------------------------------------------------------
БЫСТРЫЙ СТАРТ
----------------------------------------------------------------
1. Скопируйте SchoolBells.exe в любую папку, доступную для записи.
   Например: C:\SchoolBells\ или на рабочий стол.
   Не запускайте программу из архива — сначала распакуйте файл.
2. Запустите SchoolBells.exe.
3. Откройте вкладку «Расписание». Выберите день недели слева.
4. Нажмите «Добавить» и укажите начало и конец урока.
   Время можно вводить как 08:00, 0800 или 800 — программа
   автоматически приведёт его к виду 08:00.
5. Заполните остальные дни. Чтобы не вводить одинаковое
   расписание вручную, используйте «Копировать день…».
6. Откройте вкладку «Настройки»:
   - выберите мелодию начала урока (MP3 или WAV);
   - при необходимости выберите отдельную мелодию конца урока;
   - выберите тему оформления;
   - отрегулируйте громкость;
   - проверьте галочки «Звонить в начале урока» и «Звонить в конце».
7. Нажмите «Пробный звонок», чтобы проверить звук.
8. При необходимости настройте вкладки «Музыка» и
   «Голосовое оповещение».
9. Закройте окно — программа останется в области уведомлений
   (возле часов) и продолжит звонить.

Все изменения сохраняются автоматически. Отдельная кнопка
«Сохранить» не нужна.


----------------------------------------------------------------
РАСПИСАНИЕ
----------------------------------------------------------------
Слева показаны дни недели и количество звонков в каждом дне.
Текущий день отмечен словом «Сегодня».

  Добавить         — добавить новый урок в выбранный день.
  Удалить          — удалить выделенный урок.
  Выше / Ниже      — изменить порядок уроков.
  Сортировать      — расположить уроки по времени начала.
  Копировать день… — перенести всё расписание выбранного дня
                     в другие дни недели. В открывшемся окне
                     отметьте нужные дни и нажмите «Копировать».
                     Если в дне уже есть звонки, программа
                     спросит подтверждение замены.
  Очистить день    — удалить все уроки выбранного дня.

В колонке «Комментарий» можно указать название урока или класса,
например «1 урок» или «5А, математика». Комментарий виден
в журнале звонков.

Время проверяется при вводе. Поддерживаются форматы:
  08:00, 8:00, 0800, 800, 8, 8.30, 930, 1230.
Если время введено неверно, строка подсвечивается, а программа
не даст закрыть окно, пока ошибка не будет исправлена.

Совет: для понедельника заполните расписание один раз, затем
выберите понедельник и через «Копировать день…» перенесите его
на вторник—пятницу. После этого поправьте отличия.


----------------------------------------------------------------
КОРОТКИЙ ДЕНЬ
----------------------------------------------------------------
В списке дней недели есть восьмой пункт «Короткий день».
Это отдельный шаблон расписания. В блоке «Короткий день» слева
отметьте дни (Пн—Вс), в которые должен действовать этот шаблон.

Например, отметьте субботу и заполните «Короткий день» тремя
уроками. В субботу программа будет звонить по этому шаблону,
а в остальные дни — по обычному расписанию.

Если выбрать в списке день, отмеченный как короткий, таблица
покажет расписание шаблона «Короткий день». Изменения в нём
действуют для всех отмеченных коротких дней — это удобно, если
расписание короткого дня одинаковое.


----------------------------------------------------------------
МЕЛОДИИ ЗВОНКОВ
----------------------------------------------------------------
Вкладка «Настройки», группа «Мелодии звонков».

  Начало урока — мелодия, которая звучит в начале каждого урока.
  Конец урока  — отдельная мелодия для конца урока.

Кнопка «Выбрать MP3…» открывает файл. Поддерживаются MP3, WAV,
WMA и M4A. Выбранный файл копируется в папку SchoolBellsData,
поэтому оригинал можно переместить или удалить — программа
продолжит работать.

  ▶       — прослушать мелодию.
  Сброс   — вернуть встроенный звонок.

Если мелодия конца не выбрана, в конце урока звучит мелодия
начала. Встроенный звонок создаётся автоматически при первом
запуске, поэтому программа работает со звуком сразу.

Громкость (0—100 %) действует только на звук программы и не
меняет общую громкость Windows. Если звук всё равно не слышен,
проверьте громкость Windows и микшер громкости.

Длинная мелодия автоматически останавливается через 30 секунд.
Кнопка «Стоп» в шапке останавливает весь звук сразу.


----------------------------------------------------------------
ТЕМЫ ОФОРМЛЕНИЯ
----------------------------------------------------------------
Вкладка «Настройки», группа «Оформление».

  Авто (по сезону) — тема меняется по времени года:
      весна (март—май), лето (июнь—август),
      осень (сентябрь—ноябрь), зима (декабрь—февраль).
  Классическая синяя
  Весенняя зелень
  Летнее небо
  Осенняя охра
  Зима / Новый год
  Графит
  Тёплая терракота

В зимней теме в шапке идут анимированные снежинки. Их можно
отключить галочкой «Показывать снежинки (зимой)».

Тема применяется сразу, перезапуск программы не нужен.


----------------------------------------------------------------
МУЗЫКА НА ВСЮ ШКОЛУ
----------------------------------------------------------------
Вкладка «Музыка» предназначена для трансляции через динамики
компьютера или подключённую школьную акустику.

Музыка по расписанию:
  - нажмите «Добавить музыку…» и выберите файл;
  - в таблице укажите день, начало и конец;
  - «Каждый день» — запись будет играть ежедневно;
  - «Файл…» — заменить файл выбранной записи;
  - «▶ Проверить» — прослушать запись;
  - «Удалить» / «Очистить» — убрать записи.

Музыка включается в начале интервала и останавливается в конце.
Если в это время звенит звонок, звонок имеет приоритет.

Музыка вручную:
  - «Добавить файлы…» — добавить один или несколько файлов;
  - выберите файл и нажмите «▶ Включить»;
  - «■ Стоп» — остановить музыку;
  - двойной клик по файлу также включает его.

Файлы копируются в папку программы. Громкость музыки
регулируется отдельно и не влияет на громкость звонков.


----------------------------------------------------------------
ГОЛОСОВОЕ ОПОВЕЩЕНИЕ
----------------------------------------------------------------
Вкладка «Голосовое оповещение» позволяет записать объявление
с микрофона и затем транслировать его на школу.

Как записать:
  1. Подключите микрофон и разрешите его в Windows:
     Параметры → Конфиденциальность → Микрофон.
  2. Нажмите «● Начать запись».
  3. Произнесите объявление.
  4. Нажмите «■ Остановить и сохранить».
  5. Запись появится в архиве и сразу проиграется для проверки.

В архиве можно:
  - «▶ Прослушать» — проиграть выбранное объявление;
  - «Удалить» — удалить запись;
  - «Обновить» — перечитать список;
  - «Открыть папку» — открыть папку данных.

Записи сохраняются в формате WAV в папке SchoolBellsData.
Громкость объявлений регулируется отдельно.

Если микрофон не найден, проверьте, что он подключён, не занят
другой программой и разрешён в параметрах Windows.


----------------------------------------------------------------
ПОВЕДЕНИЕ ПРОГРАММЫ
----------------------------------------------------------------
  Звонить в начале урока — автоматические звонки в начале уроков.
  Звонить в конце урока  — автоматические звонки в конце уроков.
  Запускать вместе с Windows — добавить программу в автозапуск
      текущего пользователя. Права администратора не нужны.
  При закрытии сворачивать в трей — при нажатии на крестик окно
      скрывается, а программа продолжает работать.

Большая кнопка в шапке («Звонки включены» / «Звонки выключены»)
быстро отключает и включает все автоматические звонки. При
выключенных звонках расписание сохраняется.

Полностью закрыть программу можно через меню значка в области
уведомлений: правый клик по значку → «Выход». Двойной клик по
значку открывает окно.

Одновременно может работать только одна копия программы.
Повторный запуск покажет сообщение о том, что программа уже
запущена.

Если при закрытии окна включено сворачивание в трей, значок
может быть скрыт в переполненной области уведомлений. Нажмите
стрелку «^» возле часов, чтобы его найти.


----------------------------------------------------------------
ПАПКА ДАННЫХ
----------------------------------------------------------------
При первом запуске рядом с SchoolBells.exe создаётся папка
SchoolBellsData. Точный путь показан в «Настройках» в группе
«Данные программы»; кнопка «Открыть папку» открывает её
в Проводнике.

  settings.txt      — расписание и настройки;
  settings.txt.bak  — предыдущая копия настроек;
  default_bell.wav  — встроенная мелодия;
  melody_*.mp3      — выбранные мелодии звонков;
  music_*.mp3       — музыка по расписанию и для ручного списка;
  voice_*.wav       — голосовые объявления;
  bells.log         — журнал прозвеневших звонков;
  errors.log        — журнал ошибок (создаётся при ошибках).

Журнал звонков помогает проверить, что звонок прозвенел:
в нём записаны дата, время, урок и результат.

Резервная копия: закройте программу и скопируйте всю папку
SchoolBellsData в надёжное место. Для восстановления верните
папку на место рядом с exe-файлом.

Если папка рядом с программой недоступна для записи (например,
программа лежит в C:\Program Files), данные автоматически
сохраняются в %APPDATA%\SchoolBells. Программу лучше положить
в обычную папку, например C:\SchoolBells.


----------------------------------------------------------------
ПЕРЕНОС НА ДРУГОЙ КОМПЬЮТЕР
----------------------------------------------------------------
Скопируйте на новый компьютер два объекта:
  1) SchoolBells.exe;
  2) папку SchoolBellsData (если нужно перенести расписание,
     мелодии, музыку и записи объявлений).

Если скопировать только exe, программа запустится с пустым
расписанием и создаст новую папку данных.

После переноса в другую папку проверьте автозапуск: откройте
«Настройки», снимите галочку «Запускать вместе с Windows»
и поставьте её снова. Так в реестр запишется новый путь
к программе.


----------------------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
----------------------------------------------------------------
Нет звука:
  - проверьте громкость в программе и в Windows;
  - нажмите «Пробный звонок»;
  - проверьте, не выбран ли для конца урока файл, который
    Windows не может воспроизвести;
  - попробуйте MP3 с постоянным битрейтом или WAV;
  - проверьте, что в микшере громкости не отключён звук
    программы.

Звонок не прозвенел в нужное время:
  - убедитесь, что кнопка в шапке показывает «Звонки включены»;
  - проверьте галочки «Звонить в начале урока» и «Звонить в конце»;
  - выберите правильный день недели и проверьте время;
  - если день отмечен как короткий, проверьте шаблон
    «Короткий день»;
  - программа должна быть запущена (значок возле часов);
  - не допускайте сна ноутбука в момент звонка. Если компьютер
    проснулся позже времени звонка более чем на 5 секунд,
    этот звонок не повторяется;
  - при необходимости перезапустите программу.

Не работает микрофон:
  - проверьте, что микрофон подключён и выбран устройством
    записи по умолчанию;
  - разрешите доступ к микрофону в параметрах Windows;
  - закройте программы, которые могут занимать микрофон;
  - попробуйте начать запись ещё раз.

Не включается музыка по расписанию:
  - проверьте галочку «Включить музыку по расписанию»;
  - проверьте день недели и интервал времени;
  - нажмите «▶ Проверить», чтобы проверить сам файл;
  - музыка не запускается задним числом, если программа была
    закрыта в момент начала интервала.

Второй запуск не открывает окно:
  - программа уже работает; найдите её значок в области
    уведомлений. Возможно, окно скрыто в трее.

Антивирус предупреждает о неизвестном файле:
  - exe-файл не подписан цифровой подписью. Добавьте его
    в исключения антивируса или соберите программу
    самостоятельно (см. ниже).

Кнопка «Открыть инструкцию» не работает:
  - положите README.txt рядом с SchoolBells.exe.

Нужно сбросить настройки:
  - закройте программу, переименуйте или удалите
    SchoolBellsData\settings.txt (можно оставить .bak);
  - при следующем запуске программа создаст настройки заново.


----------------------------------------------------------------
СИСТЕМНЫЕ ТРЕБОВАНИЯ
----------------------------------------------------------------
  - Windows 10 или Windows 11 (32- и 64-битные версии);
  - .NET Framework 4.x — входит в состав Windows;
  - около 40—60 МБ оперативной памяти;
  - любой звуковой выход, слышимый в классе;
  - микрофон — только для голосовых объявлений.

Программа не требует установки, не пишет в системный реестр
ничего, кроме необязательной записи автозапуска, и не требует
прав администратора.


----------------------------------------------------------------
СБОРКА ИЗ ИСХОДНЫХ ФАЙЛОВ
----------------------------------------------------------------
Для разработки в папке находятся:
  src\            — исходный код C# (WinForms);
  app.ico         — значок программы;
  app.manifest    — манифест совместимости и DPI;
  build.cmd       — сборка;
  test.cmd        — сборка и запуск самотестов;
  tools\          — вспомогательные скрипты;
  tests\          — самотесты.

Сборка выполняется встроенным компилятором .NET Framework:
  build.cmd

Скрипт использует csc.exe из
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\ и создаёт
SchoolBells.exe. Внешние библиотеки и установщики не нужны.

Проверка логики и звука:
  test.cmd
  test.cmd --no-audio
